# Criminal Profile

ID: `gta6.mechanic.criminal-profile`

## Кратко

Впервые в серии GTA (по словам Nelson): система, отслеживающая характер преступлений игрока — ближе к оценке «какой ты преступник», чем к магазинных скидкам Honor из RDR2.

## Формулировка разработчика (Nelson)

- Отслеживает действия игрока; делит *часть* ДНК с Honor из RDR2, но отличается
- **Не** берет скидки в магазинах «за доброту» в стиле RDR2
- Оценивает стиль: профессиональный против жестокого / опасного преступника
- Агрессия мира / NPC масштабируется с агрессией игрока
- «Хорошая» отработка грязного ограбления (быстрый уход даже после стрельбы) все еще может тянуть к профессиональному стилю
- Плохую игру не наказывают блокировкой контента; оба стиля что-то упускают
- Крайний объем преступлений может влиять на сюжет / персонажей (мягкая формулировка)

Достоверность: **HIGH CONFIDENCE** (Famitsu TRANSLATION + сводки прессы); точные метры / подписи интерфейса за пределами иконки ангела / звона при поглаживании собаки в Расширенном показе: **PARTIAL**.

## Показано

- Положительная обратная связь при поглаживании собаки (иконка ангела / звон) — SHOWN
- Черт / эмодзи на портретах персонажей в интерфейсе / HUD интерпретируют как уклон Profile — INTERPRETED
