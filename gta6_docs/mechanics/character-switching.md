# Смена персонажа

ID: `gta6.mechanic.character-switching`

## Кратко

Переключение между Jason и Lucia быстрее, чем «небесная камера» GTA V; партнер под ИИ помогает; сюжет может блокировать переключение или переключать автоматически.

## Правила (разработчик + показано)

| Правило | Достоверность |
|---------|---------------|
| Переключение между Jason и Lucia | SHOWN + DEV |
| Переключение может быть заблокировано сюжетом на одного персонажа | HIGH CONFIDENCE |
| Часть миссий переключает автоматически (напр. Jason стреляет → Lucia за рулем с Raul) | HIGH CONFIDENCE + SHOWN |
| Часть миссий позволяет свободно чередовать управление в перестрелке | HIGH CONFIDENCE |
| Неуправляемый партнер следует своему дневному расписанию в убежище | HIGH CONFIDENCE |
| Можно позвать партнера на опциональные активности (напр. ограбление магазина в одиночку или вместе) | HIGH CONFIDENCE |
| Интерфейс переключения: двойные портреты; сердечная связь; маркеры эмодзи | SHOWN |
