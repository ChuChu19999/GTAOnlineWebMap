# Уровень розыска и Heat

ID: `gta6.mechanic.wanted-heat`

## Кратко

Переработанная система розыска: звезды не появляются «из воздуха» без свидетеля/тревоги; полиция работает с **описанием** (одежда, внешность, транспорт, пара, оружие, камеры CCTV) и **региональным Heat**.

## Идентичность

- EN: Wanted Level / Heat
- Официальный русский: UNKNOWN
- Тип: базовая механика свободного мира / ухода от погони в миссиях

## Правила (разработчик)

| Правило | Достоверность | Источник |
|---------|---------------|----------|
| Преступление должно быть засвидетельствовано NPC **или** сработать тревога для сообщения | HIGH CONFIDENCE | Nelson / IGN |
| Шкала из шести звезд возвращается (в GTA V было пять) | HIGH CONFIDENCE | SHOWN + пресса |
| Диспетчер очень конкретен относительно известных данных | HIGH CONFIDENCE | Nelson |
| Heat: полиция ищет по идентификаторам, не обязательно зная точную позицию | HIGH CONFIDENCE | Nelson / Famitsu |
| «Горячая» зона на карте может сохраняться после ухода; возврат рискует повторным контактом | HIGH CONFIDENCE | Nelson |
| Бросить транспорт → иконка/данные по машине могут сброситься | HIGH CONFIDENCE | Nelson |
| Сменить одежду / внешность; одежда и описание — отдельные оси | HIGH CONFIDENCE | Nelson / демо IGN |
| Разделить Jason и Lucia, если их знают как пару | HIGH CONFIDENCE | Nelson |
| Выбросить оружие, которым совершили преступление, может снизить подозрение (потерять ствол) | HIGH CONFIDENCE | Famitsu (TRANSLATION) |
| Покинуть зону Heat, чтобы снять преследование в этом регионе | HIGH CONFIDENCE | Nelson |
| Маски уменьшают опознающие данные | SHOWN | Расширенный показ |
| Полые звезды: реакция без ID преступника | COMMUNITY VERIFIED | Чтение кадров в нескольких изданиях |

## Интерфейс / HUD (показано)

Под звездами: иконки физического описания, одежды, камеры CCTV, транспорта, пары, оружия (набор зависит от ситуации).
