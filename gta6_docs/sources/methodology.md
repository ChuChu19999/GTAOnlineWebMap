# Источники и методология — GTA VI

ID: `gta6.sources.methodology`

## Принцип

До релиза приоритет — **официальные** материалы. Утечки и слухи документируются отдельно и никогда не повышаются до CONFIRMED без нового источника уровня 1.

## Основные страницы

| Источник | URL | Использование |
|--------|-----|-----|
| Rockstar — страница GTA VI | https://www.rockstargames.com/VI | Персонажи, места, издания, дата |
| Only in Leonida | https://www.rockstargames.com/VI/only-in-leonida | Тексты персонажей + мест |
| Editions | https://www.rockstargames.com/VI/editions | Издания и бонусы |
| Лента Newswire Rockstar | https://www.rockstargames.com/newswire | Переносы, предзаказ, медиа |
| Take-Two IR / пресса | https://www.take2games.com / Business Wire | Цена, формулировка одиночная, предзаказ |

## Правила достоверности (проекта)

1. Текст с rockstargames.com/VI или ленты Newswire → `CONFIRMED`.
2. Отчеты о прибылях / пресса Take-Two → `CONFIRMED` для бизнес-формулировок; не интерпретировать как детальный игровой дизайн.
3. Кадр трейлера без текстового описания → `SHOWN`.
4. Совпадение утечки 2022 с поздним официальным фактом → в официальном документе писать CONFIRMED по официальному источнику; в документе об утечке отметить «позже подтверждено».
5. Голоса актеров без указания Rockstar в титрах → максимум `REPORTED` / `HIGH CONFIDENCE` с указанием, кто подтвердил (актер / агентство / пресса).

## Правила датирования

Не смешивать:

- дату анонса;
- дату трейлера;
- дату переноса релиза;
- дату предзаказа / предзагрузки;
- дату обнаружения утечки;
- дату релиза игры;
- дату появления Online (когда объявят).
