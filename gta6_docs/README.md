# База знаний Grand Theft Auto VI

Локальная энциклопедическая и историческая база знаний о **Grand Theft Auto VI** (сюжетка) и задел под будущий **GTA VI Online**.

## Период исследования

**2022-02-04 → по настоящее время** (срез базы: **2026-09-21**)

Целевая дата выхода сюжетки (текущая официальная): **2026-11-19** (PS5, Xbox Series X|S).

## Назначение

Файлы в `gta6_docs/` — главный источник истины по GTA VI для этого репозитория. Ответы опираются на документы, а не на память чата.

После выхода игры и (отдельно) онлайн-режима структура расширяется по тем же правилам, что и база GTA Online: обновления, недели событий, объекты, экономика, баги, эксплойты.

## Текущая фаза

**ДО РЕЛИЗА.** Игра еще не вышла. Основной контент базы:

- официальные анонсы и переносы дат;
- трейлеры / Расширенный показ;
- персонажи и локации с официального сайта;
- издания и предзаказ;
- платформы;
- строгое отделение утечек и слухов от CONFIRMED.

Разделы `updates/`, `event-weeks/`, `bugs/`, `exploits/` и т.п. — **зарезервированы** под период после релиза и Online.

## Достоверность

| Уровень | Смысл |
|---------|--------|
| `CONFIRMED` | Официальный источник Rockstar / Take-Two |
| `HIGH CONFIDENCE` | Несколько независимых надежных источников |
| `COMMUNITY VERIFIED` | Устойчиво подтверждено сообществом |
| `REPORTED` | Есть сообщение, проверка неполная |
| `DISPUTED` | Источники противоречат |
| `UNKNOWN` | Данных нет |
| `DEBUNKED` | Опровергнуто |
| `LEAK ONLY` | Только из утечки; не смешивать с CONFIRMED без пометки |
| `SHOWN` | Видно в официальном трейлере / игровых кадрах, но не описано текстом |

**Правило до релиза:** кадр в трейлере ≠ полное описание механики. Не заполнять пробелы фантазией.

## Источники (иерархия)

1. **Уровень 1:** лента Rockstar Newswire, rockstargames.com/VI, Take-Two (инвесторы / пресс-релизы)
2. **Уровень 2:** GTA Wiki, специализированные базы с цитированием уровня 1
3. **Уровень 3:** Reddit, YouTube, форумы, X/Twitter
4. **Уровень 4:** утечки, разбор данных, реверс, сравнение сборок

Утечки сентября 2022 и неофициальные материалы — только в [leaks-rumors/](leaks-rumors/), с явной пометкой.
